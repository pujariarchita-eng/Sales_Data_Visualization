# AI/ML Task: Sales Data Visualization

## Overview
This project focuses on visualizing sales data using Python, Pandas, and Matplotlib. Bar and line charts are created to compare monthly sales and identify trends and patterns.

## Objective
- Create a bar chart to compare monthly sales.
- Create a line chart to visualize sales trends.
- Analyze the data and record meaningful observations.

## Tools and Technologies
- Python
- Pandas
- Matplotlib
- Jupyter Notebook

## Dataset
A sample dataset containing monthly sales values from January to December is created directly in Python. No external CSV file is required.

## Implementation
1. Create a Pandas DataFrame containing monthly sales.
2. Display the dataset and calculate summary statistics.
3. Generate a bar chart using `plt.bar()`.
4. Generate a line chart using `plt.plot()`.
5. Analyze the visualizations and print observations.

## Key Observations
- January recorded the lowest sales of 12,000.
- December recorded the highest sales of 40,000.
- Total annual sales were 283,000.
- Sales generally increased toward the end of the year.

## Conclusion
The project demonstrates how data visualization helps compare numerical values, identify trends, and communicate insights effectively. Bar charts are useful for comparisons, while line charts are useful for visualizing changes over time.

## Note
The dataset contains illustrative sample values and does not represent actual company sales.
